## Phase Goal

**Goal (verbatim from ROADMAP.md Phase 2):** Real and mock survey data can be safely and correctly converted into the Parquet/JSON artifacts the app consumes.

> MVP mode note: this Goal line is not in `As a / I want to / so that` user-story form. It is reproduced verbatim rather than invented. Run `/gsd mvp-phase 02` if a formal user story is wanted on the ROADMAP line.

<objective>
Stand up the entire real-data conversion spine as one working end-to-end path — raw CSV in, three published artifacts out, with the DATA-03 privacy checklist blocking by default in between — and then lock the pure-logic parts under a runnable self-test.

This plan implements locked decisions D-01 (one row per respondent, one column per question), D-02 (open-ended free text excluded entirely, never merely hidden), and D-03 (numeric column becomes `measure`, everything else becomes `dimension`, no manual per-column annotation).

Purpose: every later piece of this phase — the deeper privacy heuristics (plan 02-02) and the mock generator (plan 02-03) — hangs off these modules. Proving the architecture end-to-end first means an architectural dead end costs one commit, not five.

Output: `scripts/pipeline/` (schema, infer, index, privacy), `scripts/convert_enquesta.py`, `scripts/pipeline_selftest.py`, and a never-deployed raw fixture.
</objective>
