## Phase Goal

**Goal (verbatim from ROADMAP.md Phase 2):** Real and mock survey data can be safely and correctly converted into the Parquet/JSON artifacts the app consumes.

> MVP mode note: this Goal line is not in `As a / I want to / so that` user-story form. It is reproduced verbatim rather than invented. Run `/gsd mvp-phase 02` if a formal user story is wanted on the ROADMAP line.

<objective>
Deliver the second entry point into the pipeline: a synthetic survey generator that needs no real data, no input file and no privacy gate, and that produces artifacts structurally identical to the real conversion's output.

This is a separate end-to-end path through the same layers proven in plan 02-01, so it leads with its own tracer slice. It reuses `pipeline.schema`, `pipeline.infer` and `pipeline.index` unchanged — D-03's inference rule is applied to the synthetic frame exactly as it is to a real one, which is the whole point: whatever Phase 3's explorer sees in the mock dataset is what it will see in a real one.

Purpose: Phase 3 cannot build the DuckDB-Wasm and GraphicWalker explorer against an empty `public/data/`. This plan puts a real, committed, honestly-labelled Parquet file there.

Output: `scripts/generate_mock_parquet.py`, `scripts/README.md`, and the committed `mostra-sintetica` dataset.
</objective>
