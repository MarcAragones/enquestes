<objective>
Close gap G-03-4 (major): every copied share link fails to restore the chart it
encoded. EXPL-11 is currently 0% functional — not degraded, entirely dead — and
it fails silently by design (D-07's never-throw, fail-soft-to-undefined
posture), which is why nothing surfaced it before UAT.

Root cause (fully diagnosed in `.planning/debug/g-03-4-share-link-restore.md`,
status: diagnosed, confirmed by direct reproduction): `decodeShareLink`'s step-6
schema-drift guard calls `collectFieldReferences`, which recursively walks the
ENTIRE decoded object graph and collects every string found at a `fid` key, then
rejects the whole payload if any collected fid is missing from
`knownFieldNames`. But `encodings.dimensions` and `encodings.measures` are
GraphicWalker's field CATALOGUE — "every field available in this dataset" —
not "fields this chart uses. `newChart()` in the installed
@kanaries/graphic-walker@0.5.2 unconditionally appends three internal virtual
field ids to that catalogue: `gw_count_fid` (Number of records),
`gw_mea_key_fid` (Measure names) and `gw_mea_val_fid` (Measure values), sourced
from `dist/constants.js` as COUNT_FIELD_ID / MEA_KEY_ID / MEA_VAL_ID. Those
three never appear in any survey's meta.json, so they can never be in
`knownFieldNames`, so the guard rejects 100% of real specs.

The 16-test suite stayed green because `makeSpec()` is hand-authored and only
lists shelf-assigned fields — it models an idealised chart shape that
GraphicWalker never actually emits.

Purpose: restore EXPL-11 while keeping the D-07 schema-drift control that
T-03-11 introduced — narrowing WHAT it inspects, not weakening whether it
rejects.
Output: a shelf-scoped field-reference check in `src/lib/shareLink.ts`, and a
`shareLink.test.ts` fixture that models the real export shape so this regression
class cannot recur.

The two `missing` items on G-03-4 are written as "restrict to shelf channels OR
allowlist the virtual fids". Both are required, not either: restricting to shelf
channels alone still rejects a chart that places `gw_count_fid` on a shelf
(dragging "Number of records" onto an axis is an ordinary, common action), and
allowlisting alone still rejects a link whose stale catalogue lists a real field
the current survey dropped. This plan implements both.
</objective>
