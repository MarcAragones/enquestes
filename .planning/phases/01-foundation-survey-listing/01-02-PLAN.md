## Interface contracts defined by this plan

Plan 01-03 builds against these; keep the names and shapes as written.

- `SurveyCard` — props `{ enquesta: EnquestaIndexEntry; onSelect: (id: string) => void }`.
  Renders a `<button type="button">` so the whole card is one keyboard-focusable activation
  target; calls `onSelect(enquesta.id)` on activation.
- `SurveyGrid` — props `{ enquestes: EnquestaIndexEntry[]; onSelect: (id: string) => void }`.
- `LoadingSkeleton` — no props.
- `EmptyState` — no props.
- `ErrorState` — props `{ message: string; onRetry: () => void }`.
- `formatDate(iso: string): string` — Catalan long-form date via `Intl.DateTimeFormat('ca-ES', { day: 'numeric', month: 'long', year: 'numeric' })`; returns the input unchanged when it does not parse.
- `formatCount(n: number): string` — `Intl.NumberFormat('ca-ES')`.

Design token contract inherited from plan 01-01 (`src/index.css`): neutrals come from Tailwind's
built-in `zinc` ramp; `accent`, `accent-strong` and `accent-soft` are the only chromatic tokens;
`font-sans` is the D-04 typeface stack.
