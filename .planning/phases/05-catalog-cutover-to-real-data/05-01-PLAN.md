<flagged_assumptions>
The deterministic edge probe returned `unclassified`/`unresolved` for PUB-03, so its edges were derived by hand here and are recorded rather than assumed:

- **A-01 (PUB-03, "retired" means what):** retirement means the survey stops being *served* — index entry gone, artifact files gone from the working tree and from `dist/`. It does **not** mean erasure from git history; the blobs remain reachable at `176c79f`. `scripts/README.md` currently overstates this ("no hi ha manera de retirar un fitxer publicat sense reescriure l'historial de git") and is corrected in Task 2 to state both halves precisely.
- **A-02 (PUB-03, durability):** a removal that any later default-argument script run can silently undo is not a removal. Closing the `generate_mock_parquet.py` default-output hole is treated as in scope for PUB-03, not as unrelated hardening.
- **A-03 (PUB-03, blast radius):** the removal is only safe if it is provably scoped to one id. The gate for that is `verify_publicacio.py --expect-ids`, which fails on both a missing expected id and an unexpected present id, plus an explicit before/after file-count assertion.
</flagged_assumptions>
